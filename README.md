Falling Star Simulation

### Overview
This project blends real-world data and cosmic simulation:
- A **Falling Star simulation** using Newtonian physics.

### Built With
- Python (Jupyter Notebook)
- NumPy
- Matplotlib
- Pandas

---

### 1. Falling Star Simulation
- Applied gravity-based orbital decay formulas.
- Simulated the path of a star falling towards Earth from low orbit.
- Plotted trajectories and decay patterns.
